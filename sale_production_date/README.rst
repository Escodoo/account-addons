This module introduces the concept of a Production Date on Sales Orders.

The Production Date entered on the Sales Order is transferred to the invoice
generated from that order. When the invoice is posted, the analytic lines created
from it use the Production Date instead of the invoice/accounting date.

.. contents::
   :local:

Usage
=====

1. Open a Sales Order and set the Production Date.
2. Confirm the Sales Order and create the invoice from it. The Production Date is copied to the invoice.
3. Post the invoice. The analytic lines generated from the invoice are dated with the Production Date instead of the invoice date.

The Production Date can also be set manually on a customer invoice before it is
posted.
