This module allows to filter accounts by their types in General Ledger Report.

   :local:

Usage
=====

To use this module, you need to:

1. Go to Invoicing > Reporting > OCA accounting reports > General Ledger.
2. Inside the "Filter account types" tab, select the account types you wish to include in the report.
