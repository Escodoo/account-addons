This module adds an alternative calculation mode for the ICMS DIFAL base on
the Brazilian fiscal engine, applying unique base calculation mode for ICMS
DIFAL for non taxpayer partners and it is final customer yes, even for states
with double base DIFAL.

Usage
=====

To use this module, you need to:

1. Create an invoice with a partner that is not a taxpayer and is a final customer.
2. The partner must be in a state that has double base DIFAL.
3. The ICMS DIFAL base will be calculated using the unique base calculation mode.
