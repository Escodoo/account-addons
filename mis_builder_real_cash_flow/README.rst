Usage
=====

To use this module, you need to:

1. Go to Accounting > Configuration > MIS Report Templates and create a new template
using the `MIS Real Cash Flow` model as "Move Lines Source".
2. Go to Accounting > Reporting > MIS Reports and create a new report using the
template create in the previous step.
